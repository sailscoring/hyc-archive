# HYC 2025 → HalSail reproduction

Build artifacts for reproducing HYC's 2025 summer club racing in **HalSail**,
adopting DBSC's methodology. This is **Phase 3 of app issue
[`sailscoring/sailscoring#235`](https://github.com/sailscoring/sailscoring/issues/235)**
(the per-fleet sub-series / tandem investigation). Purpose: understand HalSail by
doing, and let HYC scorers see their season in it.

Source data: the published Sailwave pages under
`../sources/reshyc/results.hyc.ie/reshyc/2025/club/`. **Only real published data**
— see the caveats below for every place a value is derived rather than published.

## The model (DBSC methodology)

Every published table sits on two axes: a **handicap view** (Scratch / HPH / IRC /
PY) → a HalSail **class**; and a **race subset** (Tue Series 1, Sat Mini, …) → a
**tandem series**. Under both sits a hidden **Master** class (`TCF`, boats @ 1.000,
its series embargoed "hidden, always") that holds the real races and the finishes,
entered once. Tandems re-score the Master's finishes per view and per block.

> Naming principle: **class = `{Fleet} {View}`** (day baked in only for a
> progressive HPH view run on two independent calendars, i.e. Tue vs Sat);
> **series = `{Day} {Block}`**. Full plan and the all-fleets class/series list:
> issue #235.

## Puppeteer pilot — `puppeteers/`

Generated by [`extract-puppeteers.py`](extract-puppeteers.py) (`python3
extract-puppeteers.py`). 24 boats, **27 Master races** (16 Tuesday + 11 Saturday),
4 classes, 16 tandems.

| File | Import via | Contents |
|---|---|---|
| `classes.csv` | Classes → Import | 4 classes (Master + Scratch + HPH Tue/Sat) |
| `boats.csv` | Boats → Import | 24 boats, one row per class enrolment, with per-view handicap |
| `races.csv` | (manual: create Master series first) Schedule → Import races | 27 Master races, start datetimes |
| `finishes/<day>-<MM-DD>.csv` | per Master race: Results → Import | finish times + RET/DNF/DNS/OCS/UFD |
| `series-build-guide.md` | **manual** | the 1 Master series + 16 tandems, with exact race dates per tandem |

**Order:** classes → boats → create Master series + import races → build the 16
tandems (guide) → import finishes. After importing classes, set the two HPH
classes' local handicap name to **HPH**, and the Master series' embargo to
**hidden, always**.

## Caveats / deltas (published vs reproduced)

Per the repo rule, every derived (non-published) value:

- **Start times** are derived as `finish − elapsed` (min across finishers) from the
  per-race detail tables — HYC doesn't publish a start time. (Tue ≈ 19:15, Sat ≈
  14:30.)
- **HPH starting handicaps** (`boats.csv`) are seeded from each boat's *earliest
  published per-race HPH rating* in that day-calendar — a proxy for HYC's base
  number. HalSail's `NHC` progression then runs from there and **will not
  bit-match HYC's HPH (NHC1) algorithm**; expect HPH-table divergence. The Scratch
  and (fixed) views should match closely.
- **Owner / Helm** are both set to the published *Entrant* string (HYC publishes a
  single combined entrant, e.g. "Alan Pearson & Alan Blay").
- **DNC** boats are omitted from `finishes/` (HalSail auto-scores absentees as DNC);
  only RET/DNF/DNS/OCS/UFD are written explicitly.
- **`races.csv` Start** is `DD/MM/YYYY HH:MM:SS`; adjust if HalSail's CSV race
  import expects a different date format.
- Series 1 R1 is **Friday 2 May** (not a Tuesday) — published as-is; left unchanged.
- **Commas in names are replaced with ` / `** (e.g. `Biggs, Sargent & Johnston` →
  `Biggs / Sargent & Johnston`): HalSail's CSV import splits on every comma and does
  not honour quotes, so a quoted comma silently breaks that boat's row (it was the
  cause of "sail 21 not found" on import).

Record any reproduction gap found during the build in `../CLARIFICATIONS.md`.
